# AI Project 1 – Rule-Based AI Chatbot

## Project Overview
This project is part of the DecodeLabs Artificial Intelligence Industrial Training Program, Batch 2026.

The objective is to develop a simple Rule-Based AI Chatbot using Python.

## Technologies Used
- Python
- Jupyter Notebook
- Conditional Statements (if-else)
- While Loop
- Dictionary

## Key Features
- Responds to greetings such as Hello and Hi.
- Answers predefined questions.
- Handles unknown inputs.
- Continues the conversation until the user exits.
- Supports exit commands such as bye, exit, and quit.

## How to Run
1. Download the Jupyter Notebook file.
2. Open it in Jupyter Notebook.
3. Run the code cells.
4. Enter messages to interact with the chatbot.
5. Type `bye` or `exit` to stop the conversation.

## Project Objective
To understand basic AI concepts, rule-based decision-making, conditional logic, and continuous user interaction.
